特別支援学校 中学部段階（段階2）の「長さ（cmとmm）」の授業で使用する、直感的で視覚的な学習用Webアプリケーション（HTML/CSS/JS 完全1ファイル構成）です。

## 🌟 特徴・機能

### 1. キャラクターAI「難波先生」による個別フィードバック
- 画面上に「難波先生」（吹き出し付き）を配置。
- 知的障害の生徒にもわかりやすい優しい平仮名表記・短い文で声かけ。
- **Web Audio API** による効果音（ファンファーレ、気づき音など）＋ **Web Speech API** による自動読み上げ。
- **採点フィードバック**:
  - **正解時**: 「すごーい！しっかり はかれたね！ ◯cm ◯mm だね。はなまる！」＋大画面の花丸アニメーション＋ファンファーレ
  - **cm間違い時**: 「おしい！ 大きい 線の すうじ（cm）を もういちど 見てみよう。もう一度 答えてみよう！」＋定規のcm数字付近をハイライト
  - **mm間違い時**: 「おしい！ 小さい 線（mm）を 1、2、3… と 数えてみよう。もう一度 答えてみよう！」＋mm目盛り線をハイライト

### 2. 生徒の習熟度に応じた2つのモード
1. **✨【てだすけ あり】モード**:
   - **ルーペ拡大表示（ズーム）**: 測りたい場所（物の右端）をタップすると、その周辺が丸く虫眼鏡のように拡大表示されます。
   - **目盛りアニメーション**:
     1. cm基準線表示（太い赤線）
     2. mmカウントアップ（1mm刻みで「◯cm 1mm」「◯cm 2mm」と細い赤線がアニメーションで追加）
     3. 目的位置で停止・点滅
2. **🔥【てだすけ なし】モード**:
   - 拡大やガイド線なしで、写真・イラスト上の定規の目盛りを自分の目で読み取り、直接「◯cm ◯mm」を答える挑戦モード。

### 3. 写真読み込み・計測
- 「📷 写真をとる / えらぶ」から、カメラで撮影した写真や端末内の画像を使って学習できます。
- えんぴつ、けしごむ、クリップ、スティックのり、フォークのプリセット問題も完備。

### 4. 操作性とアクセシビリティ
- iPad等のタブレットで押しやすい大型数字テンキー（0〜9、けす、できた！）。
- UD（ユニバーサルデザイン）配慮フォント、ハイコントラスト配色。
- 外部ライブラリ不使用、単一ファイル（`index.html`）構成で完全オフライン・学校ネットワークでも動作可能。
