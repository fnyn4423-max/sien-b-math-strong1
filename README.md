# なんばせんせいと ながさを はかろう！【cmとmm】

特別支援学校 中学部段階（段階2）の「長さ（cmとmm）」の授業で使用する、直感的で視覚的な学習用Webアプリケーション（HTML/CSS/JS 完全1ファイル構成）です。

🌐 **GitHub Pages 公開URL**:  
[https://fnyn4423-max.github.io/sien-b-math-strong1/](https://fnyn4423-max.github.io/sien-b-math-strong1/)

---

## 🌟 主な機能と特徴

### 1. 「物体をものさしで測っている写真」で確実に機能！
- 生徒や先生が端末のカメラで撮影した**「ものさしと物体が一緒に写っている本物の写真」**がそのまま大画面に表示されます。
- **位置合わせバー機能**:
  - 写真の中のものさしの「🔵 0cm」と「🔴 はしっこ（右端）」に指でドラッグして合わせるだけで、写真の中の本物のものさしのスケールがアプリと完全に同期します。
  - 画面上部のセレクトボックスから、先生が撮影した問題の正解（例: 7cm 4mm）を簡単にセットできます。

### 2. 写真をタップしてズーム＆アニメーション（【てだすけ あり】）
- 写真の測りたい場所（物の右端）をタップするだけで、その位置へ**カメラが滑らかにズームアップ（拡大表示）**！
- 写真の中の本物のものさしの目盛りの真上に、
  1. **cmの基準線表示**: 写真のcm線の位置に太い赤色の基準線が表示（難波先生：「まず、大きい 線の すうじ（cm）を 見てみよう！」）
  2. **mmのカウントアップ**: 写真の目盛りの上を1mm刻みに赤線がトントンとなぞり、「1mm、2mm…」とカウント（難波先生：「つぎに、小さい 線（mm）を 1、2、3… と 数えてみよう！」）
  3. **目的位置で停止**: 端っこで線が点滅（難波先生：「ここが はしっこ！ なんcm なんmm かな？ 自分で こたえを いれてみよう！」）
- **★教育的配慮**: 生徒が自分で考える前に答えが分かってしまわないよう、**回答が入力されて「できた！」を押すまで、先生は正解の数字を言いません**。

### 3. 若くてクールな「難波先生」（眼鏡なし）
- スタイリッシュでクール、知的で爽やかな若手男性教師キャラクター（眼鏡なし・シャープな目元・スーツ姿）。
- 生徒思いの温かいセリフで、平仮名表記・短い文で声かけ（Web Speech API音声読み上げ＋Web Audio API効果音）。
- **採点フィードバック**:
  - **正解時**: 「すごーい！しっかり はかれたね！ ◯cm ◯mm だね。はなまる！」＋大画面の花丸アニメーション＋ファンファーレ音
  - **cm間違い時**: 「おしい！ 大きい 線の すうじ（cm）を もういちど 見てみよう。もう一度 答えてみよう！」＋写真のcm位置付近をハイライト
  - **mm間違い時**: 「おしい！ 小さい 線（mm）を 1、2、3… と 数えてみよう。もう一度 答えてみよう！」＋写真のmm目盛り線をハイライト

### 4. 2つの学習モード
- **✨【てだすけ あり】モード**: タップでズーム＆アニメーション支援。
- **🔥【てだすけ なし】モード**: ガイドやズームなしで、自分の目で写真の中のものさしを読んで答える挑戦モード。

### 5. UI/UX・アクセシビリティ仕様
- iPad等のタブレットで押しやすい大型数字テンキー（0〜9、けす、できた！）。
- UD（ユニバーサルデザイン）配慮フォント、ハイコントラスト配色。
- 外部ライブラリ不使用、単一ファイル（`index.html`）構成。
