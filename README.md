# なんばせんせいと ながさを はかろう！【cmとmm】

特別支援学校 中学部段階（段階2）の「長さ（cmとmm）」の授業で使用する、直感的で視覚的な学習用Webアプリケーション（HTML/CSS/JS 完全1ファイル構成）です。

## 🌟 主な機能と特徴

### 1. ものさしで物体を測った写真から学習！
- 「📷 ものさしと 写真をとる / えらぶ」から、カメラで撮影した写真や端末内の画像を使って学習できます。
- すぐに授業で試せる「📸 見本写真①（ペン 7cm4mm）」「📸 見本写真②（消しゴム 4cm2mm）」もワンタップで呼び出し可能。
- 先生用「写真の長さ設定（cm/mm）」で、撮影した物体の長さを自由に変更・設定できます。

### 2. ズームアップした大画面でのアニメーション支援（【てだすけ あり】）
- 「▶️ ズームして アニメーション」を押すと、測定ポイント（右端の目盛り付近）へ**ダイナミックにズームアップ（拡大表示）**！
- 拡大されたクリアな画面の中で：
  1. **cmの基準線表示**: 太い赤色の基準線がドーンと表示。
  2. **mmのカウントアップ**: 拡大されて目盛りが広々見える状態で、1mm刻みに「◯cm 1mm」「◯cm 2mm」と赤線がトントンと入り、ピッ音とともにカウント。
  3. **目的位置で停止**: ぴったり停止して線が点滅！「◯cm ◯mm だね！」と教えてくれます。

### 3. 若くてクールな「難波先生」AIキャラクター
- スタイリッシュでクール、知的で爽やかな若手男性教師キャラクター。
- クールながらも生徒思いの温かいセリフで、優しい平仮名表記・短い文で声かけ。
- **Web Audio API** による効果音（ファンファーレ、気づき音など）＋ **Web Speech API** による音声読み上げ。
- **採点フィードバック**:
  - **正解時**: 「すごーい！しっかり はかれたね！ ◯cm ◯mm だね。はなまる！」＋大画面の花丸アニメーション＋ファンファーレ
  - **cm間違い時**: 「おしい！ 大きい 線の すうじ（cm）を もういちど 見てみよう。もう一度 答えてみよう！」＋定規のcm数字付近をハイライト
  - **mm間違い時**: 「おしい！ 小さい 線（mm）を 1、2、3… と 数えてみよう。もう一度 答えてみよう！」＋mm目盛り線をハイライト

### 4. 2つの学習モード
- **✨【てだすけ あり】モード**: ズームアップ＆アニメーション支援で、目盛りの読み方を段階的に学ぶ練習モード。
- **🔥【てだすけ なし】モード**: ズームなしで、自分の目で全体を見て直感的に「◯cm ◯mm」を答える挑戦モード。

### 5. UI/UX・アクセシビリティ仕様
- iPad等のタブレットで押しやすい大型数字テンキー（0〜9、けす、できた！）。
- UD（ユニバーサルデザイン）配慮フォント、ハイコントラスト配色。
- 外部ライブラリ不使用、単一ファイル（`index.html`）構成。
